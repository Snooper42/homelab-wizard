    Changelog¶

    What changed in each version of Homelab Wizard, newest first. Each version's notes are also its release notes on GitHub, and what the app shows before an update.

    Notes are grouped as New, Improved, and Fixed, one line each, in plain words. The pull requests behind a version hold the details. Versions before 0.9.0-beta were tagged afterwards, at the commit where each one ended.

    Unreleased¶

    New¶

    • Storage with logos and fewer words: on the iPhone and iPad, Settings › Storage shows each app's logo beside its folder's size, and says when it was measured (5 hours ago) instead of Each app's folder, as the nightly backup measured it… Photos and films on their own drive aren't counted. An app whose logo ships under its part's name (Immich, MoneyMatter) shows it everywhere, as on the computer.
    • One command checks the real thing: homelab doctor --live (or scripts/verify-mac-live.sh) runs the Docker engine, a container's whole life, a backup and a blind restore (a volume, a PostgreSQL database, and Duplicati), the scheduled agent, and each connected app for real, in a throwaway workspace that leaves the household's apps and data alone, and prints a PASS/FAIL table to paste back.
    • Warned weeks before a disk fills: the watchdog keeps each disk's free space once a day, and when one is filling fast enough to be full within two weeks, an alert says which, how fast, and about when, before a full disk can stop the apps or damage their databases.
    • Gold Tier apps: homelab apps marks the household's core apps (Immich, Vaultwarden, Paperless-ngx, Jellyfin, Navidrome, Seerr, Sonarr, Radarr, Prowlarr, AdGuard Home, Tailscale, Duplicati) as gold and every other as experimental, and homelab apps --gold lists only the core; --json gives each app's tier. Nothing is removed.

    Improved¶

    • Bills on the Homelab app shows a pay period as the computer does: on the iPhone and iPad, each pay period starts with whose paycheck it is, says what checking holds on payday once its own payments are out and what the period itself comes to, lists every account after it with what changed, and says under each bill how it's paid: its kind, on a card, from another account, or from someone else.
    • Finish setting up says how many are left: on a phone's Status, the card reads 8 left instead of 2 of 10 done · 8 left, as the iPhone's 8 steps left.

    Fixed¶

    • This Month on the Homelab app's Transactions reads the computer's month: it took the phone's own date where the rest of Finances takes the computer's, said -$0 when nothing had gone out, and showed three zeros on a month with nothing in it yet. Now it follows the computer's today, nothing out is $0, and an empty month says Nothing yet this month. At the largest text its heading no longer fills the screen.
    • Duplicati won't back up an unplugged drive: the photos, Jellyfin, books and synced Files backups now check their folder first, and refuse to run while it is empty, so the last good backup stays the newest instead of one that records every photo deleted. Backups shows the job failed, and the watchdog alerts. Jobs made before get the check on the next night.
    • Paperless-AI's setup code is where the note says: Paperless-AI now asks for a setup code on its first page when the homelab has already given it Paperless's token; its note says the code is in appdata/paperless-ai/setup-code and in ./homelab logs paperless-ai, and the nightly run reads it there.
    • Calibre-Web's "default login still works" was a false alarm: with no library set yet, Calibre-Web sends every page to its sign-in, which the check took for the default login working. It now reads that answer as its library isn't set yet and names the setting (Admin › Edit Basic Configuration › Location of Calibre database).
    • Uninstalling from a Windows PC takes back the rule that sent the domain's names to AdGuard Home, including the one an older homelab left without a label, which pointed at an address no device had and broke every name under the domain on that PC (the owner's, Nov 28).
    • An app you keep home only is checked to really be off the internet: the watchdog, homelab doctor and homelab domain status now ask the internet's DNS where each home-only app's name leads, and alert when it still answers from outside (as Vaultwarden and Paperless-ngx did through tunnel hostnames left from before), instead of only saying home only. Keeping an app home only without the Cloudflare token no longer claims it is off the internet.
    • The homelab signs in to qBittorrent 5.2: it answers a right password with 204 and no words where older ones said Ok., and the homelab took that for refused the sign-in. So Connect apps couldn't stop qBittorrent sharing a finished download or give it the VPN's port, and Tidy Up and the downloads card couldn't see its torrents.
    • Connecting the apps says why it can't read an app's key: when an app saved its API key as another account (as Docker on Linux can), Connect the apps now says so and how to fix it, instead of open it once, then try again, which never helped.
    • An update that can't start goes back by itself: an app's update stops it to copy its data first; when its new version then couldn't start (a port already taken, say), it stayed stopped until someone noticed. It now goes straight back to the version it ran, with its data from just before, and its updates wait until you release them.
    • The nightly jobs find Docker Desktop's tools: under Docker Desktop installed for your account only, the background agent couldn't find its sign-in helper, so the nightly updates' downloads failed; it now looks in Docker Desktop's own folders, with no need to install the jobs again.
    • homelab doctor says what happens after a restart: on a Mac, After a restart says in plain words whether FileVault stops it at the unlock screen, whether it logs in by itself, whether it turns on again after a power cut, and how you hear that it's waiting for you.
    • A restore from Proton Drive on a new Mac gets whole files: homelab rebuild and the restore test first download each backup file Proton Drive (or any cloud drive) still keeps online only, and say how many, so Duplicati never reads a placeholder; a drive that doesn't hand one over stops it with what to do.
    • Connect apps sends Seerr's requests to Sonarr and Radarr again: a Seerr that already had them, set up by hand or by an older homelab, refused the correction (request/body/id is read-only), so both steps failed. A step an app turns down now says what the app said, in its own words, not the address it was sent to and its raw reply.

    [0.46.0] - 2026-11-27¶

    v0.46.0 to v0.46.10, Nov 27, 2026: 18 changes. Among them: The iPad's sidebar says Homelab Wizard once; An app to add, never cut short; The iPad's sidebar is its mark and name, as the computer's.

    New¶

    • The iPad's sidebar says Homelab Wizard once: its title at the top, without the same name again in a row under it.
    • An app to add, never cut short: on the iPad, a category's Add to tiles say what each app does in full instead of cutting it with …; on the iPhone a tile is its logo and name, as on the computer's web page. VoiceOver still reads what it does.
    • The iPad's sidebar is its mark and name, as the computer's: without Your apps, at home under Homelab Wizard.
    • Backups' two cards say what the computer's say: on the iPhone and iPad, Restore test is Passed and when (a failure's reason too), without 12 files checked, all the same as now; Off-site is the place and its folder (Proton Drive · homelab-backups), without Encrypted before it leaves or the settings file unless it isn't copied.
    • One Live on the iPad's Status: beside the sidebar, Status no longer shows its own Live at the top as well as the sidebar's at its foot. With the sidebar hidden, Status shows it again.

    Improved¶

    • Backups: every copy with its logo, and fewer words: MoneyMatter's attachments show MoneyMatter's logo instead of an M. Paused says only who waits for which drive, without their last copies (13 days ago) are kept; the password vault export gives its age (9 days ago) without the sentence before it.
    • Analytics without empty space while it starts: until the first readings come, there's no timeline card saying Drawn as Status reads the apps, every 10 seconds, and Processor and Memory have no empty band where their line will be. The same on the iPhone and iPad.
    • Subscriptions' yearly sums in whole dollars: Household $60, $40 a year, not $60.00, $40.00 a year beside $460; a month's price keeps its cents ($21.99 a month). The same on the iPhone and iPad.
    • What an app to add does, whole or not at all: on the computer, each tile in All apps and a category's Add to list says what the app does in full, over two lines, instead of cutting it with …. On a phone's narrow page the tile is its logo, its name and Install; its page says the rest.
    • An app to add says less: its facts keep their figures, without Runs in the homelab, Ready as it comes or Beside, before it installs under them.
    • Status' category lines aren't cut short: a category names two of its apps only when both fit, else one and a count (Nginx Proxy Manager +3, not Nginx Proxy Manager, AdGuard Ho…). On a phone's narrow page the pill says ✓ 4 instead of ✓ 4 running, leaving the room to the names. The iPhone and iPad follow the same rule.
    • On a phone, Status' menu says where you are: it reads All apps while All apps shows, instead of Overview.
    • An app's page says less, as on the iPhone: Updated 8 hours ago without the one before is kept for a week; Its updates are held without the sentence after it; In the nightly backup gives the time of its last copy, or Outside the homelab; an explanation of its log ends with the lock and On this Mac · llama3.2.
    • Backups' cards are cards: Last night, Restore test and Off-site each have their padding, a gap between them and one height, on the computer and the web page. On a phone, each skipped app's name sits beside its logo instead of on a line of its own.

    Fixed¶

    • A phone can no longer wipe the homelab: the web page's Take the homelab off this machine, with its options to delete the apps' data and the backups, is gone, and it can't remove old containers' volumes either. Taking the homelab off stays on the computer, behind its typed confirmation.
    • A rollback never says it worked when it didn't: putting an app back to the version before its update now checks that the database's copy loaded cleanly, keeps only the copy made for that update (never an older night's), and leaves the app stopped, with today's data set aside, if only part of it could be put back.
    • The nightly backup warns when it would back up nothing: when the backup drive or Proton Drive's folder isn't there, or the photos' drive is unplugged and its folder empty though it was backed up before, the night fails and you get an alert, rather than a backup that records every photo as deleted.
    • Explain these logs keeps your passwords out: homelab logs <app> --explain hides the settings' passwords and keys from the model, as the app and a phone already did.

    [0.45.0] - 2026-11-26¶

    v0.45.0 to v0.45.10, Nov 26 to 27, 2026: 22 changes. Among them: An app's page in the Homelab app says less; Settings' Setup row shows how many steps are left; Backups' Skipped list in a word, as on the computer.

    New¶

    • An app's page in the Homelab app says less: on the iPhone and iPad it shows its facts and its problems, not explanations. Gone: The watchdog checks it every 15 minutes, Stopped for a while, it starts again by itself, It starts by itself within a minute of the drive being plugged in again, Its files, and its database's copy, every night, and what Roll back keeps. An app the watchdog stopped says Its log says why under what happened; a native app's backup reads Outside the homelab.
    • Settings' Setup row shows how many steps are left: on the iPhone and iPad, Setup reads 4 left even when the app opens straight on Settings. It loads the checklist once this device may see it, and again on pull to refresh. The Setup page loses its lead line and the Face ID note under Do the 2 I Can Do for You; each step still says why it matters, as on the computer.
    • Backups' Skipped list in a word, as on the computer: on the iPhone and iPad, a skipped copy says Stopped, Not running or Removed instead of a sentence, and the list's footer about drives is gone (each row already says Waiting for the Hobbies drive).
    • The old Status cards are gone from the Homelab app, as on the computer: on the iPad, the watchdog's checks, Protection, Recent Alerts and Storage no longer sit under the app list. Every alert sent is now Settings › Alerts Sent, newest first, with Snooze… on one still failing. Memory nearly full is a card at the top of Analytics, with the biggest apps and Stop. In Settings, Subscriptions you don't pay and What the apps keep are gone: Subscriptions and Analytics say both.
    • Status on the iPad, as the computer's: in landscape, Status fills the width beside the sidebar with the Overview's three cards side by side, then Analytics, Subscriptions, Backups and the categories. A category opens its tiles, and an app its page, in the same place. The sidebar is Status, Finances and Settings, as the computer's: Backups is in Status, Setup in Settings. Links, Siri, ⌘K and the menu bar open apps and pages there.
    • Setup is one of Settings' pages on the iPhone: the Setup tab is gone, leaving three tabs: Status, Finances and Settings. Setup is a row near the top of Settings, showing how many steps are left. While some are, a Finish setting up card on Status' Overview shows the count and a progress bar and opens it. A homelab://setup link opens it too.
    • Backups is one of Status' pages on the iPhone, as on the computer: the Backups tab is gone. Backups is a row on Status under Subscriptions, with its count and what was skipped, and Status' tab badge counts it. The Backups card, a homelab://backups link and Siri all open it there. Its words are fewer too: Due, None yet, Under half the night before's …, and Last night shows only its time.
    • Fewer words on Status in the Homelab app, as on the computer: on the iPhone and iPad, the Overview's cards are their title, their figure, and problems only. Gone: Checked 4 minutes ago, Every night at 03:30, Last run Thu 7:48 AM, Updates daily at 04:00 and Plugged in. What's left shows only when something's wrong: Mealie stopped, Mealie skipped, Updates paused, On battery. Subscriptions reads $1,457 a year · $150 a month and drops its Library line, since … and instead of.
    • Status' cards at the largest text sizes: on the iPhone and iPad, a card's name (Backups, This machine) no longer gets cut short by the words beside it. At the largest sizes those words move under the name, and a stopped app's logo sits beside the first line of what happened to it.
    • No "needs you" on the Homelab app: on the iPhone and iPad, Backups' list of copies that weren't made is called Skipped, Setup says What's left to set up, and how this machine is doing., and a task that went wrong says What Happened over its reasons.
    • Subscriptions on the iPhone, as the computer's: Status has a Subscriptions row that opens what your apps save, for example $1,457 a year, $150 a month, instead of 15 subscriptions. Library services like Spotify are on their own line, since they only count if you own the media. Below that: where the saving comes from by kind of app, what more the apps you don't run could save, then each paid service once as a tile with its logo, its price a month and a year, and the apps that replace it.
    • Analytics on the iPhone, as the computer's: Status has an Analytics row that opens the processor, memory and drives as three cards, each with the app that uses the most, then the apps' processor and memory over the minutes it's been open, read every 15 seconds. Below that is what each app uses, heaviest first: memory as a bar, processor, and its folder on disk. Day, Week and Month show the computer's own record of the last day, week or month. Your phone can now read that record and the subscription prices (UsageHistory, SavingsRows), read-only.
    • A category's page on the iPhone as the computer's: tap a category on Status to see its apps as tiles, two across: each with a dot for how it is, its logo, one line (Up 4 days, Stopped at 3:12 AM), Open or Start, and ⋯ for the rest. Under them, Add to Media shows the catalog's other apps, faded; you add them on the computer. Find an app searches the page.
    • Prowlarr and the download apps start again after the VPN updates: an app that searches or downloads through the VPN could no longer be started once Gluetun was updated (No such container). Start, Restart, the battery saver and a Stop for a while now make that app again onto the new VPN, keeping its settings.
    • An app's page says what it does before you install it: the page for an app you don't have now reads its guide: What it does, What it can replace at its price from Subscriptions, about how much memory it takes and how it updates, Day to day, what it Works with (each opening its own page), Setting it up, Ideas to try, and Learn more links to its own site.
    • Every alert sent, under Settings › Alerts: the alerts the homelab sent now sit on Alerts' page, newest first: each says when its problem cleared or who snoozed it until when, and one whose check still fails has Snooze… (for an hour, a day, or alert again now), on the computer and on a phone allowed to change things.
    • Memory nearly full, on Analytics: when the apps use nearly all the memory Docker has, Analytics says how much and since when, with the biggest apps, each with Stop (not on a phone that only looks).
    • Analytics is only the machine's numbers: the old cards under it (the watchdog's checks, Protection, Recent alerts, Downloads, This week, what the apps keep and what's using power) are gone, as the redesign has it; the processor, memory, drives and each app's use stay.

    Improved¶

    • Analytics' figures agree with the rest of Status: each app's processor is a share of the whole machine, as the card's total is, so the busiest app reads 43% beside 51% in use instead of 171%.     • The app could open links other than web and email.
    • An app update without GitHub's checksum wasn't refused.

    0.5.0 - 2026-10-23¶

    Live Status, and apps that heal themselves. Status follows Docker as things happen, and the homelab fixes or undoes what breaks.

    New¶

    • Status updates live, following Docker's own events through the background agent.
    • The watchdog restarts an app that hangs, and an update that leaves an app not answering is rolled back.
    • Explain this log: the AI model on this machine reads an app's log and says what's wrong, in plain words. The log never leaves the machine.
    • Kiosk mode: Status on a TV or a wall screen.
    • Update shows what it brings before it starts: the newer releases' notes.
    • Progress bars for longer jobs.

    Improved¶

    • Status notices an app that runs but doesn't answer, and settings that aren't applied yet (Fix it applies them).
    • The power card is live, with each busy app's last few minutes.
    • Background work yields the CPU to the apps people are using.
    • The app's screens are rebuilt in TypeScript and Preact, one screen at a time.

    0.4.0 - 2026-10-22¶

    Windows and Linux. The app, the installers, and self-update on every system, not just the Mac.

    New¶

    • Windows and Linux builds of the app, published for every change.
    • One-line installs: install.sh on Linux and the Mac, install.ps1 on Windows.
    • The app updates itself on Windows and Linux.
    • External drives, backups, battery saver, and starting Docker work on Windows and Linux as on the Mac.
    • Windows and Linux find the apps by name with a domain.
    • Start Jellyfin from Status on Windows and Linux.
    • Update apps in the menu bar and tray.

    Improved¶

    • When an app fails to start, the app says why.
    • When Docker refuses your account, the app says so instead of calling Docker stopped.
    • doctor reads the sleep setting on Windows and Linux, and warns about SELinux labels that keep apps out of their folders.
    • AdGuard Home runs beside systemd-resolved on Linux.
    • Windows and Linux are no longer called "this Mac".
    • Panels open as sheets.

    Fixed¶

    • Self-update on Linux stopped itself halfway.
    • Linux treated ports below 1024 as taken just because only root may use them.
    • Setting up a homelab off the Mac, or with Go installed.
