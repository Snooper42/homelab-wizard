    Getting Started¶

    From an empty computer to a homelab the whole household uses, without reading any code. Set aside an afternoon; most of it is waiting for downloads. The steps below show a Mac; on Windows, Linux, or a Steam Machine only the first section differs.

    Tip

    The desktop app's Setup screen walks through the same steps with a live check for each one, and does the technical ones for you. This page explains what each step is for and what to have ready.

    What you need¶

    Why Cost
    A computer that stays on Every app runs on it: a Mac (a Mac mini, or a MacBook kept plugged in), a Windows 10 or 11 PC, a Linux machine, or a Steam Machine. 16 GB of memory is comfortable; 8 GB runs the Start here apps. Already owned
    A free Tailscale account Gives every app a private https:// address that opens on your own phones and computers, at home and away. Nothing is published to the internet. Free
    A cloud folder for backups Encrypted copies of everything leave the house every night. Proton Drive is what this homelab uses. An existing plan
    An external drive (optional) Movies, music, books, and photos that do not fit on the computer. Already owned
    A domain on Cloudflare (optional, later) Short addresses such as photos.example.com, and photos, passwords, documents, and music open away from home without Tailscale. It also needs the router's admin page, to give the computer an address that never changes. See Later: a domain of your own. About $11 a year

    1. Install the basics¶

    On a Mac:

    1. Install OrbStack, the engine the apps run in: download it from orbstack.dev (Apple Silicon), open the download, drag OrbStack to Applications, and open it; it asks for the Mac's password once to finish. (Homelab Wizard's Setup screen links to the same page with Download OrbStack.) With Homebrew instead:
    brew install --cask orbstack

    Open OrbStack once and turn on Start at login in its settings. Optional, with Homebrew: brew install smartmontools lets the homelab read each drive's health and warn before one fails; everything else works without it.

    1. Install Homelab Wizard. The app isn't signed with an Apple Developer ID yet, so macOS stops it the first time. Either way below takes about a minute, and you do it once; after that the app keeps itself current (Update now on the line at the top of the window).

    With Terminal (one line, no warning, because macOS doesn't stop downloads made from Terminal):

    curl -fsSL https://raw.githubusercontent.com/Snooper42/homelab-wizard/main/install.sh | sh

    It downloads the newest build from Releases › Latest, checks it against GitHub's SHA-256 checksum, copies it to Applications, and opens it.

    Without Terminal (the browser):

    1. On GitHub › Releases › Latest, download Homelab-Wizard-macOS.dmg and open it.
    2. Drag Homelab Wizard onto Applications, then open it from Applications.
    3. macOS says it cannot verify the app: click Done (not Move to Trash).
    4. Open the Apple menu › System Settings › Privacy & Security, scroll to Security, and click Open Anyway beside “Homelab Wizard” was blocked.

    5. Enter the Mac's password, then click Open Anyway once more. It opens like any other app from then on.

    6. Open Homelab Wizard. On a new Mac it offers Set it up for me: it makes ~/Homelab from the homelab files it carries, with no git or Terminal needed. Later, Update now on the line at the top of the window brings both the homelab files and the app up to date, keeping your settings, data, and own apps, and saving a copy of any file you changed as .local.

    To work on the homelab itself instead, clone it (the first time, macOS offers to install its command line tools; accept), and brew install go for the ./homelab commands:

    git clone git@github.com:Snooper42/homelab-wizard.git ~/Homelab

    Either way, Homelab Wizard finds ~/Homelab on its own and opens on Setup. Every new homelab starts in Home mode: no domain, and every app at an address on your tailnet.

    On Windows, Linux, or a Steam Machine¶

    The steps are the same with each system's pieces (Host has the details):

    Windows 10 or 11 Ubuntu, Debian, Fedora, Arch Steam Machine (SteamOS, desktop mode)
    The engine Docker Desktop with WSL 2 (winget install Docker.DockerDesktop), started at sign-in Docker Engine and its compose plugin; your user in the docker group Setup › Set up Docker for me puts Docker in your home folder, where SteamOS updates leave it alone
    The files Set it up for me in the app, or git clone into your user folder, outside OneDrive Set it up for me, or git clone into ~/Homelab Set it up for me, or git clone into ~/Homelab
    The app In PowerShell: irm https://raw.githubusercontent.com/Snooper42/homelab-wizard/main/install.ps1 \| iex, or GitHub › Releases › Latest › Homelab-Wizard-Windows-Setup.exe (until the builds are signed, SmartScreen asks once: More info › Run anyway) curl -fsSL https://raw.githubusercontent.com/Snooper42/homelab-wizard/main/install.sh \| sh, or Releases › Latest › the .deb, .rpm, or Arch package The same install.sh line (it puts the AppImage in ~/Applications), or Releases › Latest › the AppImage: chmod +x, open it, then Setup › Add to the app menu (right-click it there › Add to Steam to open it in Game Mode)
    Terminal commands homelab.cmd instead of ./homelab ./homelab ./homelab

    Each app build carries the homelab CLI and the homelab files, so Setup's buttons work without Go or git. Update now brings the homelab files up to date and replaces the app with its newest build, as on a Mac. Settings › This PC (This machine) can start the tray icon at login, and the AppImage can add itself to the app menu; both follow it if you move it or swap in a newer one.

    2. Work down the Setup screen¶

    The steps are grouped as Needs you, Can wait, and Done.

    • Each step says first what it gives you, then what to do. One with more to know right now has a chevron that opens it.
    • A step that didn't work says why under it, and what to press once that is put right.
    • A step moves to Done when its check passes. Check again runs every check again.
    • Backups and Alerts when this machine is down sit under Can wait for the first week: get the apps going, then do them within the week. After that they count as left to do again, and the Setup tab's number says so.
    • Do the N I can do for you runs every step that is ready, one after another. It stops at the first that fails, or when what is left needs you: a setting, a choice, or something only a person can do.
    Step What it gives you What you do
    OrbStack is running (Docker Desktop or Docker on Windows and Linux) The engine for every app. Nothing, once it's open.
    This laptop stays plugged in and open (MacBooks only) The apps stay reachable: plugged in, the homelab keeps the Mac awake (it never does on battery). Keep it on the charger with the lid open: closed, a MacBook sleeps unless a display is connected.
    The homelab is started The homelab's own apps running (updates, backups, alerts), and a settings file with a strong, unique password for each one. Click Start the homelab. The first start downloads every app and takes a while.
    Addresses on your tailnet (Tailscale) An https:// address for every app that opens on your own phones and computers, at home and away, with nothing published to the internet. Click Set up the addresses and sign in to Tailscale in the browser window it opens (make a free account there if you have none). In the Tailscale admin console › DNS, turn on HTTPS Certificates. No auth key is needed.
    This Mac opens the tailnet addresses The addresses in Status open on this Mac too, not only on your phones. Install the Tailscale app on the Mac and sign in with the same account.
    Password manager account Vaultwarden, used through the Bitwarden apps, for everyone's passwords. Shown once Passwords is installed. Click Open sign-ups for 10 minutes, create an account for each person at the passwords address, and let the window close.
    Two-step sign-in A stolen password alone opens neither the vault nor the homelab's settings. In each Vaultwarden account turn on two-step login with an authenticator app (keep the recovery code with the recovery kit). In Nginx Proxy Manager add a personal administrator and turn on Two-Factor Auth for it, then tick Done. The homelab's own proxy account (NPM_API_EMAIL) keeps it off, because the homelab signs in with it.
    Backups leave this machine Somewhere safe for the nightly encrypted backups: a cloud drive survives fire and theft, an external drive restores faster. Click the button for where they should go: Use Proton Drive, Use iCloud Drive (or Google Drive, OneDrive, Dropbox, whichever syncs on this Mac), or Use the … drive for an external drive. Each makes a Homelab Backups folder there. Any other folder: Settings › BACKUP_DESTINATION › Choose….
    Backup jobs in Duplicati Settings, databases, and photos encrypted into the backup folder every night, so a dead disk loses nothing. Click Create the backup jobs. Then, in Settings, Copy DUPLICATI_SECRETS_PASSPHRASE into Vaultwarden and write it on paper: it is the one key to every backup.
    Alerts on the phone A message on the phone when an app, a backup, or the connection fails. Click Set up the alert token. In the ntfy app on your phone, add the ntfy address with user phone and the password from Settings › NTFY_PHONE_PASSWORD › Copy, then subscribe to the alert topics.
    Scheduled jobs The homelab starts again after a restart, backs up at night, and checks itself every 15 minutes. Click Install the jobs.
    Alerts when this machine is down An email when the Mac itself stops, which the homelab cannot report on its own. Create a free check at healthchecks.io (15-minute period and grace) and put its ping address in Settings.
    Tailscale on phones and computers The apps open on each device, at home and away. Install the Tailscale app on each phone and computer, sign in with the same account, then tick Done.
    Ad blocking on every device Ads and trackers blocked on every device signed in to Tailscale, with no router change. Shown once Ad blocking is installed from Choose apps. Click Set up ad blocking, then in the Tailscale admin console › DNS add the address it shows as a custom nameserver and turn on Override DNS servers.

    If a step does not turn green, open Settings › This Mac (This PC, This machine) and click Make a diagnostics report. It writes one file with every check and log, with all passwords and tokens removed, that you can share when asking for help.

    Once every step is done, Setup leaves the sidebar. It comes back by itself, with a count, if a step comes undone (a token runs out, the backup drive goes away) or the homelab has an update; ⌘4 (Ctrl+4) opens it any time. The machine's details stay in Settings › This Mac, and Status keeps a line on how this machine looks after the homelab.

    Later: a domain of your own¶

    Home mode needs no domain. When you want short addresses such as photos.example.com, or want some apps (photos, passwords, documents, music) to open on a phone without Tailscale, put your domain in Settings › HOMELAB_DOMAIN and Save. Setup then swaps the tailnet step for these:

    Step What it gives you What you do
    This machine keeps its address The app names keep pointing at the Mac at home. In the router's app, reserve the Mac's current address (the step shows it), then tick Done.
    Home DNS answers (AdGuard Home) The home network learns the apps' names, and ads are blocked for every device that uses it. Click Set up AdGuard: it answers AdGuard's first-run wizard with a new login.
    Cloudflare API token Lets the homelab get the padlock certificate and publish addresses. Create a token with the three permissions the step lists, and paste it in Settings. Never paste it anywhere else.
    Addresses and certificate https:// addresses for every app, on the Mac and on phones at home. Click Set up the domain. The first certificate takes a few minutes. Apps you install afterwards get their addresses by themselves.
    This Mac finds its apps by name The addresses open on this Mac too, also with a VPN on, and for apps added later. Click Find the apps on this Mac and enter the Mac's password once.
    Access away from home (Cloudflare Tunnel) Photos, passwords, documents, and music work on mobile data, with no ports opened on the router. Create a tunnel in Cloudflare Zero Trust, paste its token in Settings, and click Start the tunnel.
    Phones and computers use the home DNS Ads are blocked on every device at home. The app names already work at home without it, with a VPN on too: Set up the domain points them at this Mac in Cloudflare's DNS. On each device, set the Wi-Fi DNS server to the Mac's address, then tick Done. With a VPN app on a device, turn on its Allow LAN connections instead.

    3. Choose more apps¶

    Open Choose apps.

    1. Start here has the five things most homes want first: Photos, Passwords, Movies and TV, Music, and Files. Click the ones you want.
    2. Every other app is under Add more, where each says what it does and which subscription it can replace. Tick what you want, or pick a preset such as Household (smart home, groceries, to-dos, saved links, and a start page) or Media automation (the *arr apps, Seerr for requests, and qBittorrent behind a VPN).
    3. Read the plan on the right. It says in one line how many apps it installs and lists the ones you picked; helpers, port moves, and settings written wait under Details. When an app needs a setting first (the VPN key for qBittorrent, for example), the plan names it and the field to fill in appears below, with where to find it.
    4. Click Install.

    If the apps would need more memory than the Mac has room for beside macOS and everyday apps, the plan says so and names the heaviest to leave out. On an 8 GB Mac the Start here picks fit; Immich's face and smart search (machine learning) is the one to add with care.

    4. Set up each person's phone¶

    In Home mode, first install the Tailscale app on the phone and sign in with the same account as the Mac: the apps' addresses open only on devices in your tailnet.

    Install To Sign in at
    Tailscale Reach the apps at home and away (Home mode) your Tailscale account
    Bitwarden Use the shared password manager the passwords address, with the account from step 2
    Immich Back up photos and browse them by face, place, or thing the photos address
    The Homelab app (iPhone and iPad) See Status, Backups, and Finances, and start or restart an app, behind Face ID pair it with the QR code in Settings › Phones (below); built with Xcode on your Mac for now (apple-client)
    ntfy Get the homelab's alerts (the person who looks after it) the ntfy address, as user phone
    Jellyfin or Infuse Watch the movies and shows you own the Jellyfin address
    Any Subsonic music app, or Feishin in a browser Listen to your music the music address

    To open an app on a phone without typing its address, click its row in Status and then Open on a phone on its page: it shows the address as a QR code for the phone's camera, with what the phone needs (home Wi-Fi or Tailscale) and the app's phone app. Everything else opens in a web browser. Install Homepage from Choose apps for one start page with every app on it, kept up to date by the homelab; the Inventory lists every address too.

    Each person can have their own sign-in, through Pocket ID, the household's sign-in app (without it, the card offers Set up the household's sign-in first):

    1. In Settings › People, click Add a person.
    2. Give their name, email, and the apps they use (All the apps, or Only these), and click Add them.
    3. The homelab makes their account and says so, with two ways to hand it over: Show their sign-in to scan opens their welcome page on the computer (a one-time link to sign in with their phone's face or fingerprint, as a code for its camera too, the apps they use, and their own tab on the start page); Open the fridge sheet opens a page with just their apps. The welcome page holds their sign-in link and their films and music password, so keep it for them: the fridge sheet is the one to email or hang up.

    Later, Make a new sign-in link makes a fresh link (the old one stops working), and Remove turns their sign-in off and keeps their data.

    Jellyfin and Navidrome have a password of their own, so that Infuse, the TV apps, and music apps such as Arpeggi can sign in. With JELLYFIN_API_KEY and a Navidrome administrator's login in Settings, adding someone makes those accounts too (one password for both, on their welcome page and nowhere else); New music and films password gives them a new one, and Remove turns them off. With a domain, ./homelab sso setup then lets Karakeep, Paperless-ngx, Mealie, Vikunja, and Open WebUI sign in with Pocket ID.

    For the person who looks after the homelab: Settings › Phones › Pair a phone shows a QR code. Scan it from the Homelab app on an iPhone or iPad, and the app shows Status, each app's page, and Backups, at home or over Tailscale. A phone without the app (Android, a visitor's) scans it with its camera instead, and gets the same screens in its browser (Share › Add to Home Screen keeps it as an app). Your partner's phone pairs the same way; beside each phone, Sees Finances or Changes Finances adds the household's Finances to it (only for a phone paired with the https link).

    5. Day to day¶

    • Status shows every app with a coloured dot. A category where everything runs folds into one line; what needs a look stays open at the top. Each row has one button, Open (or Start when stopped); a click on the row opens the app's page, where it can be restarted, updated, stopped, or removed, its log read, and its nightly updates and alerts switched off. Sign-in details on the page of each app the homelab made a login for (the proxy, AdGuard, Duplicati, Kopia, PsiTransfer, Beszel, Nextcloud) shows the user and copies the password. When something is down, Fix it shows a plan and puts it right. The menu bar icon shows the same at a glance.
    • This week on Status is the Sunday summary at any time: apps, backups, the restore test, attacks caught, and disk space, with what needs a look marked. What the apps keep shows the largest app folders, and an app that was down part of the week says so (for example 96.2% up this week).
    • Updates to the apps install themselves at night. Pause them with Pause on Status's Nightly updates tile, or from the menu bar, before something important. If an update breaks an app, Roll back on its page puts the previous version back (kept for a week), and an app that stays unwell after an update is put back by itself.
    • Updates to the homelab itself show by themselves as one line at the top of the window (and Update to … in the menu bar): the app looks every 15 minutes and downloads what it finds. Update now puts the homelab files in place, then the newest Homelab Wizard, checked, and opens it again (on Windows, asking for an administrator's approval only when the app is in Program Files; on Linux, when it was installed from a package). If it cannot go in place, the line says why, with the release page to install it by hand.
    • Finances in the sidebar is the household's money, typed in by hand and kept on this computer: who gets paid and when, the accounts and cards, and the payments that repeat. Its dashboard shows checking over the next month, which paycheck covers each bill, and every account after each paycheck; Net worth draws it month by month, with your home's and car's equity. Nothing connects to a bank, and the file goes off-site with the nightly backup, encrypted.
    • Tidy Up in the sidebar keeps the music, films, shows, books, and audiobooks on the media drive in order. Drop a download into a folder it watches (Downloads, to start) and it works out what it is, cleans it up, and files it into the right library; What I did today lists each one with Undo, and each library's tab has its own clean-up. Anything it throws away goes to the Trash (Tidy Up).
    • Backups run at night. The Backups screen shows each app's newest copy and when a restore was last proven; once a month, click Test a restore to prove they work (Backups), and the homelab reminds you.
    • When something breaks, an alert arrives on the phone. Open Status and click Fix it, or read the app's log and restart it; with Ollama on this computer, Explain this under the log says in plain words what it shows. If that does not help, make a diagnostics report.
    • Text too small? Cmd and + or − (Ctrl on Windows and Linux) makes the whole app bigger or smaller, and Cmd and 0 goes back.
