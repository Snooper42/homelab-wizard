# Tidy Up's look: the owner's references

Screenshots of a finance app whose style Tidy Up should borrow, read by the Tidy Up loop (`.claude/prompts/tidy-loop.md`, **The look**) at the start of every look round. They're kept here for reference only: the app never loads them, and Tidy Up takes their layout and feel, never their name, logo, icons, words, or pictures.

To add one: on GitHub, open this folder, **Add file › Upload files**, and commit to main. Then add a line below.
