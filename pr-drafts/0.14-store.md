- **`web/src/store.ts`**: a screen's data kept between visits: the last reading, when it was read, and why the last read failed. One read at a time (asked during one, it reads once more after it), `fresh(maxAge)` reads only when out of date, `set()` keeps an action's answer, `stale()` marks it out of date, `watch()` draws.
- **app.ts**: Status (`statusData`, with its cards read alongside), Backups (`backupsData`, `jobsData`), Setup (`hostData`, `stepsData`) and Settings (`settingsData`) each read into a store and draw from it. Picking a screen draws what is kept and reads it again only when it is out of date or over a minute old; Settings are not read again while something is typed, so it stays. ⌘R, Ctrl+R, F5 and the engine's `refresh` read the screen now. `status:changed` reads Status when it shows, and otherwise marks it out of date, read when Status is picked. An install marks Status and Settings out of date (new apps, new settings). A Setup step's answer redraws Settings' marks.
